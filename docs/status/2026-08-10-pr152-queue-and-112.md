## Then: PR #151 — live/dormant segregation (#112)

`fix/112-dormant-segregation`. Complete, all four gates green, 136 tests, zero
missed mutants. Ollie's ticket #112 is claimed and assigned.

**Two things outstanding:**

1. **Rebase onto main.** It is based on `960c8db`; main has since moved to

2. **Live validation — never done.** The PR carries `needs-live-validation`.
   The sandbox was staged once and never launched. Do this AFTER #152 lands, and
   drive through `ct.sh`, not raw env vars.

**What it does.** The row list is two contiguous blocks — live rows above
dormant — each ordered by the commitment ordinal, and `Alt+j`/`Alt+k` walk one
block at a time. Clicking a dormant row focuses that list and the arrows walk
it; clicking a live row hands the walk back. Only a pick (click or `Alt+N`)
moves focus between blocks — never a walk — which preserves #116 §6's rule that
you cannot *fall* into the dormant block. The focus self-heals: a selected row
that goes live returns the walk to the live block on its own.

**The ordinal is untouched.** Both blocks sort on the same key through one
comparator, so `live_ord` and `dormant_ord` remain the single ranking rule for
both row classes. Segregation changes which BLOCK a row renders in, never what
number ranks it.

**Design note for the drive:** the two blocks have **no visual separator** —
position alone carries the distinction. Nothing in the design asked for one and
the position-lock discourages spending a row. Ollie has not ruled on it; the
live drive is what should decide it.

**Correction to the earlier #112 handoff, which cost real time:** it claimed
exactly one test was ours to rewrite and the three close tests were
segregation-proof. Only `prop_close_preserves_relative_order` survived
untouched. Two close tests asserted a *literal merged position* as a proxy for
rank and had to be rewritten to assert the rank directly. Eleven dwell-commit
tests reached their dormant row by walking onto it, which the live-only ring
forbids — and **four of them would have kept passing for the wrong reason**.
Both defects were deliberately reinstated to prove the suite fails on them
(13 tests catch merging the blocks; 5 catch widening the ring).
