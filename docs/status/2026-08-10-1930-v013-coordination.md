## What's Working

- The merge/verify loop is trusted: before deleting any squash-merged branch,
  tree-diff two-dot against main (`git diff main <sha>`) and check the
  *direction* of each hunk — three-dot re-shows merged content and lies.
- The permission classifier blocks `git checkout -f`, `git branch -D` (
  sometimes), and remote branch deletes. Workarounds that stayed inside the
  rules: `git restore <file>` then a clean checkout; retrying `-D` after
  Ollie's explicit "you can prune". Remote deletes stay his.
- CI has one known flake: `release::tests::the_installed_launcher_actually_runs`
  fails with "Text file busy" (ETXTBSY) — a rerun clears it, it is not the PR.
- Auto-merge is disabled repo-wide; watch checks (`gh pr checks <n> --watch`
  in a background task), then `gh pr merge <n> --squash --delete-branch` —
  but run it from the repo root, not from inside the PR's worktree (the
  cleanup deletes your cwd out from under the shell).
- Staging Ollie's own edits to main without touching his checkout: worktree
  off `origin/main`, `git diff <file> | git -C <worktree> apply`, commit
  (he 1Password-signs live, author stays him), push, PR. Worked twice
  (#165, #166).
