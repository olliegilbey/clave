## Important Discoveries

- Idle sidebar cost, a hypothesis that has NOT been measured: zellij sends every bar a full `PaneUpdate` whenever any pane changes, and `PaneInfo` carries `cursor_coordinates_in_pane` (`zellij-utils-0.45.1/src/data.rs:2392`), so cursor moves may count as changes. Each of 15 bars then pays the decode. zellij-server source is not vendored, so the trigger is unconfirmed. A possible design: a hidden bar unsubscribes from PaneUpdate and catches up when shown; that risks nav and coherence, which read the pane frames (#162, #178). The human has not yet said yes to the sandbox study.
- A staged sandbox writes bare `clave hook <Event>` entries into the human's real `~/.claude/settings.json`. Live sessions pick them up at once, so cut the release right after a drive that adds hook events (FOOTGUNS, and the run 45 ledger entry).
- `just qa`'s launch wait polls `clave dev status` every 2 s, which probes every zellij session socket and costs the live server CPU. To wait for a launch at no cost, poll `pgrep -f 'zellij --server .*/<name>$'` and then run `scripts/qa-drive.sh` directly.
