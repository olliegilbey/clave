**The loop (filmed with an instrumented bar, trace in the FOOTGUNS
"paint-echo" entry):** a swap's repaints arrive queued and STALE (~5 echoes
of the pre-swap width within ~10ms). The judge-every-paint machine spent 3
asks in a millisecond on echoes, the 3-ask walk lapped the whole
three-position swap cycle, and the lap's transit paints re-armed the next
burst. The "frozen width" spin guard never engaged because the walk kept the
width MOVING — reset-on-movement was the second half of the bug.

**The fix (model.rs `width_effects` + `width_cooldown_elapsed`):**
1. An ask sets `swap_in_flight` — the machine records paints
   (`last_painted`) but judges none until main.rs's
   `set_timeout(WIDTH_COOLDOWN_SECS = 0.15)` fires and
   `width_cooldown_elapsed()` judges the LATEST paint once. First mismatch
   still asks immediately (no idle-starvation regression; timers always
   deliver).
2. `walk_spent: Option<(bool, u8)>` — budget of `WALK_ASK_CAP = 3` per
   mode-INTENT, never re-armed by movement; cleared by target landing,
   intent change (toggle/peek), focus loss. A too-narrow window rests
   instead of looping at cooldown cadence.
3. Timer sharing: Event::Timer echoes ELAPSED seconds; main.rs classifies
   by `TIMER_KIND_CUTOFF_SECS = 0.5` (width 0.15 below, peek 0.9 above —
   the dwell-era classify_timer scheme revived, recovered from commit
   `15b03a6~1`). The width leg runs on EVERY expiry (inert unless in
   flight); the peek decrement only on long expiries with peeks pending.
4. `widths_at(cols)` — during `awaiting_hydration` only, the painted width
   picks the render profile (the pane is store truth); kills the ~200ms
   expanded-ink flash on collapsed cold start. D16 untouched elsewhere.

## Important Discoveries

- The zellij log survives session restarts and is user-global; mark its
  line count (`wc -l`) before a drive and read only the tail. A fresh
  launch line is `clave-bar: loaded v0.1.3 build=<sha>`.
- `Event::Timer(f64)` carries the elapsed ≈ requested seconds — verified
  from this repo's own deleted `classify_timer` (git show `15b03a6~1`).
- The cold-start "expanded flash" Ollie reported was INK, not geometry:
  the log showed cols=30 from the first paint with `hyd=true` and the
  default expanded profile drawn squeezed. Do not chase a geometry bug
  there; it is fixed via `widths_at`.
- A plugin reload cannot change a session's swap layouts; fixed-cols
  geometry changes need a fresh launch. Reload DOES exercise the
  hydration path (state wipe).
- Staging refuses while the sandbox session lives; the kill is Ollie's:
  `zellij kill-session clave-test-qa-182-d-1d57 && zellij delete-session
  --force clave-test-qa-182-d-1d57`.
