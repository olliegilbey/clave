## Important Discoveries

**`FOOTGUNS.md:141` IS NOW WRONG AND NOT YET FIXED.** It reasons about which of
`title`/`summary` survives an older binary stripping store fields, concluding
`summary` heals within one turn while `title` can be permanently lost. Measured on
CLI 2.1.220 today, **the cadences are inverted**: `custom-title` is written *per
turn* (33 occurrences in one 656-line session), so `title` re-derives reliably;
`ai-title` is absent from many sessions entirely, so `summary` does not
re-derive. That entry's risk acceptance was built on the old cadence. **Correcting
it is a live task** — it is tracked inside #111 but the file still says the old
thing.

**A null `live_session` is the HEALTHY default, not an unmigrated row.**
`hook.rs:436` holds it at `None` whenever the reported id equals the minted uuid.
Reading "null on all rows" as "all rows need migration" is wrong and became a
Codex P1 today before being corrected (#106).

**There is no warm migration for a new store field.** `clave release` writes new
hook commands into `~/.claude/settings.json`, but agents already running keep
firing the *previous* binary, which lacks the field. **The cold restart is the
migration.** Measured today. Do not reinvent a warm path — one was written and
withdrawn inside an hour.

**PATH order is load-bearing on upgrade.** `cargo uninstall clave` before putting
the launcher on PATH leaves no `clave` at all. Correct order: prepend to PATH in
the shell config → `exec $SHELL` → verify → uninstall → `hash -r`. This actually
happened today, mid-upgrade, with the session already killed.

**The release pipeline fails on Linux.** v0.1.2's `release.yml` failed both musl
targets (`openssl-sys` cannot find OpenSSL); both macOS targets passed. **No
release object was created, so nothing broken is public**, and the documented
install path (`git checkout v0.1.2 && just release`) never touches these
artifacts. Every path to `openssl-sys` runs through `[dev-dependencies]`. Full
diagnosis in the #35 comment dated today.

**Approaches already refuted — do not retry:**

1. **Backfilling `live_session` from the newest transcript in a project dir** —
   the heuristic #99 exists to avoid.
2. **Prompting live agents to warm a new store field** — measured, does not work.
3. **Pushing anything straight to `main`** — `enforce_admins: true`, required
   `test`/`wasm-build`. Everything goes through a PR, including a version bump.
4. **Deleting dormant store rows to reduce clutter** — a dormant row is a
   resurrectable conversation. The fix is navigational separation (#112).
