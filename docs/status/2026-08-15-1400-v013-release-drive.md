## Important Discoveries

1. **REGRESSION (Ollie, live, sandbox): toggle desync on a fresh terminal
   tab** — Alt+c left the sidebar width UNCHANGED while the text flipped
   short-form/long-form each press. Belief and pane answered to different
   authorities. The width-truth rework deletes this class (text and width
   both follow zellij's reported layout). This is the acceptance test.
2. **REGRESSION (Ollie, live, comparing stable vs #197 build): border-drag
   snap-back is gone.** Stable: dragging the sidebar/content border and
   releasing snaps the sidebar back to its set width (the deleted seek did
   this). #197 build: dragging smaller lets terminal content cover the
   sidebar. This is the "minimum width only survives launch" decision
   surfacing as real UX loss — **Ollie's verdict is effectively in: he
   expects snap-back.** Note: reported-truth alone does NOT restore it (a
   drag changes no swap position; zellij marks the tab damaged, and a
   damaged tab's next switch RE-APPLIES the current layout — so one toggle
   restores width; passive on-release snap-back needs a deliberate design).
   Open design question for Ollie + next session — do not silently rebuild
   the seek.
3. **Scripted toggles double-fire**: zellij appends a blank message to every
   CLI `zellij pipe`; the bar counted empty payload as a press. Proven by
   store-flag double-move, seq +2 per press, zero discards. Keyboard is
   single-fire. Blank-payload discard is half of the width-truth agent's
   brief; until it lands, never drive Alt+c by script.
4. **Permanent stuck-tab desync measured** (12 presses, focus change, 60s
   idle — never recovered): the old machine checks movement direction only,
   never position. Root cause of both regressions above.
5. **The sandbox has one bar per tab** (#186 inverted — see the 1030 file).
   Multi-instance behaviour IS sandbox-testable.
6. **Ollie on the overnight width redesign**: "allowing an agent free reign
   to fix things last night may have been a bad idea." Treat #197 as
   needing his sign-off at each step from here, not autonomous completion.

## Language reset — MANDATORY, first action

Ollie's terms, locked verbatim this session; write into
UBIQUITOUS_LANGUAGE.md and sweep recent docs (QA-DRIVE.md, checklist,
FOOTGUNS entries from today) for violations:

- **The sidebar** collapses/expands. NEVER "collapse the fleet". The
  **fleet** is the set of agents/tabs a session spins up — launched,
  killed, seeded; never collapsed.
- **Terminal tab** = Alt+t. **Agent tab** = Alt+a → pick repo → "new" or
  "resume".
- **The sidebar is singular in UX language**: one continuous sidebar, not
  "each tab's bar". Per-tab instances are implementation detail; the UX
  contract is that they're indistinguishable — today's regressions are that
  abstraction leaking.
- **NEEDS A TERM (ask Ollie, don't coin unilaterally)**: the non-sidebar
  pane where a terminal or Claude runs (both are "the terminal"
  ultimately). Propose 2–3 options to him.
