# Spike S1 — background repaint (THE ARCHITECTURE GATE)

Proves invariant #11: a `clave-bar` plugin can render a status glyph for a
**non-focused** agent row and update it live on a `zellij pipe` message
without stealing focus. See `.superpowers/sdd/task-5-brief.md` for the full
step-by-step and `docs/superpowers/specs/2026-06-30-clave-orchestrator-design.md`
§3 / §5 / §6.5 for the invariants this spike is gating.

This is a findings-log **template**. The plugin, layout, and wasm artifact
were authored and built in an author-only dispatch; the interactive steps
(launch Zellij, push `zellij pipe` snapshots, observe repaint, tear down)
require a live terminal + a human watching and were **not** run as part of
authoring this file.

## Verdict

**PENDING — run the Zellij validation interactively.**

PASS = non-focused glyph/colour updates live on pipe, stale seq (lower or
equal to the last-applied seq) is ignored, focus never moves to the plugin
pane.

FAIL = any of: plugin does not load; glyph never appears/updates; the pane
steals focus on load or on pipe; stale seq is applied (state regresses).

**On FAIL: STOP.** Do not start Task 6 or any subsystem plan. Revisit spec §3
(reconsider `rename_tab`-based painting or forking cfal) and re-brief.

## zellij-tile 0.44.3 API surface used (verified against vendored source)

Checked against
`~/.cargo/registry/src/index.crates.io-*/zellij-tile-0.44.3` and
`zellij-utils-0.44.3` (both fetched locally as transitive deps). All names
the brief assumed exist verbatim in 0.44.3 — **no API deltas were needed**:

- `zellij_utils::data::PipeMessage { source, name, payload: Option<String>,
  args, is_private }` — `.name` / `.payload` match the brief exactly.
- `zellij_utils::data::PermissionType::ReadCliPipes` exists, with display
  string `"Control command line pipes and output"`.
- `zellij_tile::shim::request_permission(permissions: &[PermissionType])`
  matches the brief's call signature.
- `ZellijPlugin::pipe(&mut self, pipe_message: PipeMessage) -> bool` has a
  default no-op impl (`false`); overriding it as in the brief is correct.
- All of the above flow through `zellij_tile::prelude::*`, matching the
  brief's single `use zellij_tile::prelude::*;` import.
